# ⚽ Weltmeisterschaft Predictor (Tipiko-Orakel)

Hi! Ich habe mal als interessierter Maschinenbauer versucht, für die WM ein ML-Modell zu bauen, das die Spiele mit ca. 56% Genauigkeit vorhersagt. 

Schaut es euch gerne mal an! Wenn ihr etwas findet, was man besser oder anders machen könnte, lasst es mich wissen.


## Details zum Projekt

* **Modell:** Random Forest Classifier
* **Input-Daten:** 
    * Marktwert des Nationalkaders
    * Vergangene Länderspiele (ab 01.01.2016 bis 27.05.2027)
    * ELO-Ratings
    * Durchschnittliches Alter des Kaders
* **Fakt auf den ich solz bin:** Keine einzige Zeile Vibe-Coding!
